Jev Lab

Small projects built on typesafe-ai/jev, a model that answers multiple-choice questions with probabilities. Each project runs through a local Node server that keeps the API key off the browser.

Projects

AI Gladiator

A real-time 2D fight against Jev. Every half second Jev reads both fighters' position, velocity, stamina and cooldowns, and picks one of 12 controls.

  • Keyboard or touch
  • Rule-based opponent works offline
  • Shows each decision's probabilities

ColderHotter

Coding Navigator

Paste a LeetCode-style problem and start writing a solution. Jev compares each batch of edits against a reference map of valid approaches and tells you whether you're getting hotter or colder. It never shows you the answer.

  • Python and JavaScript
  • Updates while you type
  • Code is never executed
