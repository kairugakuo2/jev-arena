Coding Navigator

Pick a problem and start writing. While you type, a meter slides toward hotter when your edits move toward a working algorithm and toward colder when they drift away. It points the way without ever showing you the answer.

  • All 150 NeetCode problems, filtered by pattern and difficulty
  • Starter code in Python or JavaScript
  • Paste in any other problem you want to practice
  • Your code is judged, never run

1. Two SumEasy 
class Solution:
    def twoSum(self, nums, target):
        seen = {}
        for i, x in enumerate(nums):
            if target - x in seen:
                return [seen[target - x], i]
            seen[x] = i

AI Gladiator
